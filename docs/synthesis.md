# Enamel: synthesis

Enamel is a translucent semantic harness for agentic generation. It exposes the structure, relationships, constraints, and intent of a system in a form that agents can use to generate and evolve it coherently.

Rather than asking an agent to reconstruct a system's logic from source code and scattered artifacts, Enamel provides a structured semantic space that constrains exploration while leaving room for implementation choices. It makes the system's underlying logic available to generation without requiring every decision to be prescribed upfront.

Enamel is coherent with Peter Naur's *Programming as Theory Building*: both recognise that software evolution depends on understanding the system, not merely manipulating its code. Enamel explores how this understanding can become an explicit, machine-usable substrate for agentic work.

> Make system meaning available to generation, so that generated changes remain consistent with the system they extend.

## Knowledge base: a complementary perspective

The knowledge-base dimension extends the same approach beyond program structure to organisational and domain knowledge. A shared semantic substrate could unify information from different sources, validate consistency, and expose reliable context to agents.

This is a complementary application of the underlying idea, rather than the primary definition of Enamel.
